# US-058: Dungeon goblins hunt the DM, then become a post-exit summon

**Status**: Implemented  
**Source**: James — goblins should aggro the DM while he explores; random dungeon spawns; exiting unlocks goblin summon and goblins then ignore the DM (PPs and buildings only)  
**Priority**: P1  
**Roles**: Dungeon Master, Paper Pusher

## User Story

As the Dungeon Master, while I crawl the dungeon **goblins spawn in it and hunt me**. When I **exit to the overworld**, I **automatically unlock goblin summon**, and from then on goblins **do not aggro me** — they hunt **Paper Pushers and buildings** (US-011).

## Context

Today:

- The generator places **skeletons** (and the Baja boss) in rooms/hallways (`MonsterSpawnPlanner`). **Goblins are not** a dungeon catalog spawn.
- `Enemy.aggro_faction` can be DM / PLAYERS / BOTH. Goblin scene is **PLAYERS** (`goblin.tscn`), so live goblins already ignore the DM. Skeleton/boss hunt the DM during the crawl.
- DM HUD already has a **goblin summon** (US-055 near-DM placement, US-014 mana cost 20). Catalog `unlock_id` for goblin is **empty**, so the button is available from match start — including while still trapped in the dungeon (US-015).
- After exit, goblin **raid** on factories/buildings is US-011.

This story owns the **phase split**: dungeon-hostile goblins until first successful exit, then minion/raid goblins. It does **not** redo raid melee (US-011), near-DM placement (US-055), or mana cost (US-014).

## Open defaults (confirm with James)

| Topic | Default for v1 | Why |

| Dungeon spawn | Scatter **goblins** on generated dungeon walkable cells (mids + hallways). Not in the **start** room. Not in the **exit** room (boss stays US-017). | Crawl threat without camping spawn or the boss arena. |

| Start-room safety | No goblin (or other catalog spawn) in the start room — keep existing start-room empty combat. | Fair spawn. |
| Exit unlock | On the **first successful dungeon exit** this match (US-015), host unlocks goblin summon (`DmUnlocks`, suggested id `goblin`). No Dew/boss pickup required. | “Gets the ability … automatically.” |

## Independent Test

Generate a dungeon: at least one goblin is in a mid or hallway, not in the start room. As DM, walk into range: the goblin chases and can melee the DM. Goblin HUD summon is unavailable. Exit to the overworld: goblin summon unlocks. Summon a goblin near the DM (US-055). That goblin (and any leftover dungeon goblins) do **not** chase the DM; they chase a Paper Pusher in range and can raid a factory (US-011). A joining client sees the same unlock and aggro rules.

## Acceptance Criteria

1. **Given** a successful generate, **When** monster spawns are inspected, **Then** at least one goblin is on a walkable dungeon cell that is not the start room and not the exit room; count is in the signed range; skeletons/boss packages still exist.
2. **Given** the DM has **not** exited, **When** a dungeon goblin is in aggro range of the DM, **Then** it acquires the DM, pathfinds (US-056), and can melee him. It does not treat the DM as an ally.
3. **Given** the DM has **not** exited, **When** they open the DM HUD, **Then** goblin summon is locked (not castable; no mana spent).
4. **Given** the host accepts the **first** dungeon exit this match, **When** that exit resolves, **Then** goblin summon is unlocked on the host and the DM HUD can cast it (mana still required).
5. **Given** goblin summon is unlocked, **When** the DM successfully summons, **Then** placement follows US-055 and the new goblin **does not** aggro the DM.
6. **Given** the DM has exited, **When** any living goblin picks a target, **Then** it may aggro Paper Pushers and raid buildings (US-011) and MUST NOT aggro the DM — including leftover dungeon goblins and a DM standing next to them.
7. **Given** PathValidator / existing planners, **When** this ships, **Then** start-room Dew, dice, and the exit boss still place; goblin spawns MUST NOT consume the start-room or exit-room packages.
8. **Given** a joining client, **When** the host has already exited (or not), **Then** they observe the same unlock state and goblin faction behavior (no second generate, no client-side unlock).

## Functional Requirements

- **FR-001**: `MonsterSpawnPlanner` (or successor) MUST be able to place goblins from the existing catalog (`monsters/goblin.tscn`) onto generated dungeon walkable cells. Host-only generate (001 / US-015).
- **FR-002**: Goblin dungeon spawns MUST exclude start-room cells and exit-room cells. Prefer mid rooms and hallway cells with the same occupancy/exclusion rules as other catalog monsters (not on entrance/exit cells or their 4-neighbors).
- **FR-003**: Until the match’s first successful DM dungeon exit, dungeon goblins MUST aggro the DM (`AggroFaction.DM` or equivalent). They MUST use the shared pathfinder (US-056).
- **FR-004**: Goblin DM summon MUST be gated on unlock id `goblin` (or equivalent) granted **only** by that first exit. Pre-exit casts MUST fail without spending mana.
- **FR-005**: After the first exit, the host MUST set goblin targeting so they aggro Paper Pushers and may raid buildings, and MUST NOT aggro the DM. Apply to **all** current and future goblins this match.
- **FR-006**: Post-exit summon placement, mana cost, and raid AI remain US-055 / US-014 / US-011. This story MUST NOT move spawn to world origin or skip raid HP.
- **FR-007**: Unlock and faction MUST be host-authoritative and included in late-join / match-reset the same way as `knightling` (US-016).
- **FR-008**: Skeletons, Baja boss, fountain, and pickups MUST still spawn under their own stories. Goblins are additive.

## Multiplayer Requirements

- **MR-001**: Dungeon goblin positions come from the host layout/spawn set; clients MUST NOT generate extra goblins.
- **MR-002**: Unlock and “has the DM exited” MUST be the same on every peer.
- **MR-003**: Aggro/raid target selection MUST run on the host; clients replicate goblin motion/combat only.

## Edge Cases

- DM dies in the dungeon before exiting: goblins still hunt him; respawn at entrance (US-015); summon stays locked.
- DM dies after exiting: unlock persists; goblins still ignore him.
- Re-entry after exit: leftover dungeon goblins still do not aggro the DM.
- Two exits: unlock is once; do not re-grant or toggle.
- No goblin placed (tiny/infeasible layout): generation may still succeed; unlock on exit still happens so overworld summon exists.
- Goblin HUD missing: restore the US-055 path, but keep it locked until exit.
- Chain Lightning (US-038) is knightling-only; do not triple goblin summons here.
- Crib Death (US-041) stays gremlins at the exit landing; this story does not add a goblin timer.

## Key Entities

- **Dungeon goblin**: Catalog spawn in the crawl; hunts DM until first exit.
- **Goblin summon unlock**: Granted on first successful dungeon exit; gates HUD/mana summon.
- **Post-exit goblin**: Same scene; aggro Paper Pushers + raid buildings; never the DM.
- **Pre-exit phase**: US-015 crawl window.

## Assumptions

- One dungeon per match. First accepted US-015 exit is the phase flip.
- Goblin art/scene already exists; no new sprite required.
- Paper Pushers remain unable to enter the dungeon (US-015 / US-003).

## Out of Scope

- Goblin trap laying (US-044 Random Encounter).
- Goblin HP/damage passives (Challenge Rating, +1 Swords).
- Changing mana costs or near-DM radius.
- Replacing skeletons or the Baja boss with goblins.
- Auto-summon-on-interval (Crib Death pattern).
- Client-side generation.

## Required New Art Assets

None. Reuse `monsters/goblin.tscn` / `monsters/goblin.png`. HUD can reuse the existing goblin summon control, gated until unlock.
