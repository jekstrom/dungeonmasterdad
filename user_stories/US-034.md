# US-034: DM Skill Tree UI (UI only)

**Status**: Draft  
**Source**: James — DM + Dad skill tree panels; tooltips; no gameplay spend; specific Art deliverables  
**Priority**: P2  
**Roles**: Dungeon Master

## User Story

As the Dungeon Master, I open a Skill Tree UI with **DM** and **Dad** tabs so I can browse **9 passives + 1 ultimate** per tree and read hover tooltips — without this story spending currency, applying passives, or spawning anything.

## Context

Today `gui/dm/skill_tree.tscn` is a stub: one `GridContainer` (3 columns) with buttons **Skill 1–9** plus an **Ultimate** button, instanced under `gui/dm/dm_hud.tscn`. Open/close is `DmHud._toggle_skill_tree_hud()` (visibility flip), called from `DmManager._show_skill_tree_hud()` when the DM interacts with the world **Skill Tree doodad** (`doodads/skill_tree.gd` → `SkillTreeDoodad`, prompt **F**). There are no real names, no second tree, and no tooltips.

World placement of the doodad is US-032 (exit forest). Unlock/spend/combat effects are **out of this story**.

## DM tree content (copy locked for UI labels/tooltips)

**Row 1 — Lightning (knightlings)**  
1. **Overcharged** — Increase distance traveled by knightlings.  
2. **Spark** — Reduces time between knightling attacks.  
3. **Chain Lightning** — Summon 3 knightlings instead of 1.  

**Row 2 — Gremlins**  
1. **Minions** — Gremlins can carry 1 more item.  
2. **Blind one-legged monkeys** — Gremlins turn invisible.  
3. **Crib Death** — Automatically summon 1 gremlin from the dungeon exit every min, but they only live for 15 secs.  

**Row 3 — Goblins**  
1. **Challenge Rating** — Increase goblin hp.  
2. **+1 Swords** — Increase goblin atk dmg.  
3. **Random Encounter** — Goblins can now lay traps.  

**Ultimate:** **TSB** — Summon the TSB.

(These strings are **UI copy only** in this story.)

## Independent Test

As DM, interact with the Skill Tree doodad (or HUD toggle if present): panel opens. See **DM** and **Dad** tabs. On DM tab: 3×3 passives labeled with the nine names above plus ultimate **TSB**, in Lightning / Gremlins / Goblins row order. Hover each node: tooltip shows name + short effect text. Switch to Dad: nine placeholder passives + placeholder ultimate, each with placeholder tooltips. Close the panel. Clicking nodes does not change mana, unlocks, or spawn minions. A Paper Pusher never sees this UI.

## Acceptance Criteria

1. **Given** the DM HUD is active, **When** the Skill Tree open path runs (doodad interact → existing toggle), **Then** the Skill Tree UI becomes visible.
2. **Given** the Skill Tree UI is visible, **When** the DM toggles it closed (same path and/or Esc), **Then** it hides and the rest of the DM HUD still works.
3. **Given** the UI is open, **When** the DM views tabs, **Then** there are exactly two trees: **DM** and **Dad**.
4. **Given** the **DM** tab, **When** nodes are listed, **Then** there are **9 passives + 1 ultimate**, with labels **Overcharged, Spark, Chain Lightning, Minions, Blind one-legged monkeys, Crib Death, Challenge Rating, +1 Swords, Random Encounter**, and ultimate **TSB**, in the row order above.
5. **Given** any DM node (passive or ultimate), **When** the DM hovers (or focuses) it, **Then** a tooltip shows that node’s **name** and **short effect text** from the DM tree content list.
6. **Given** the **Dad** tab, **When** nodes are listed, **Then** there are **9 placeholder passives + 1 placeholder ultimate**, each with a visible placeholder name.
7. **Given** any Dad node, **When** hovered/focused, **Then** a tooltip shows placeholder name + short placeholder effect text.
8. **Given** locked/unlocked chrome, **When** nodes render, **Then** locked vs unlocked are visually distinct **without** requiring a spend or unlock RPC for this story.
9. **Given** the DM clicks a skill node in this story’s build, **When** the click resolves, **Then** no passive is applied, no currency is spent, and no TSB / knightling / gremlin / goblin spawn is triggered by this UI.
10. **Given** a Paper Pusher client, **When** they play, **Then** they do not see the DM Skill Tree panel.

## Functional Requirements

- **FR-001**: The Skill Tree UI MUST open and close through the existing DM entry path: `SkillTreeDoodad` interact → `DmManager._show_skill_tree_hud` → `DmHud._toggle_skill_tree_hud` (replace stub content inside `gui/dm/skill_tree.tscn` / scripts as needed). Esc-to-close SHOULD work if not already present.
- **FR-002**: The UI MUST provide two selectable trees: **DM** and **Dad**.
- **FR-003**: Each tree MUST present **9 passives + 1 ultimate** in a readable **3×3 + ultimate** layout (rows = themes on the DM tree).
- **FR-004**: DM tree node labels and tooltip bodies MUST match the **DM tree content** section (UI copy).
- **FR-005**: Dad tree MUST use placeholder names and tooltip text for all 10 nodes.
- **FR-006**: Every node MUST expose a hover/focus tooltip with **name + short effect text**.
- **FR-007**: Locked vs unlocked MUST be expressible as UI chrome only. This story MUST NOT implement spend currency, prerequisite gates that grant power, or host unlock writes.
- **FR-008**: Node activation in this story MUST be UI-only (no gameplay side effects listed in Out of Scope).
- **FR-009**: Placeholder button art is allowed. Final icons are Art (task); missing art MUST NOT block labeled buttons + tooltips.
- **FR-010**: Only the DM HUD hosts this panel (not PP HUD).

## Multiplayer Requirements

- **MR-001**: Opening the Skill Tree is local UI on the DM’s client; other peers need not mirror panel open state.
- **MR-002**: Because this story has no spend/unlock, no host skill-unlock replication is required here.

## Edge Cases

- Skill Tree doodad missing (US-032 not placed): HUD-only toggle (if added) still opens; otherwise document blocked open until doodad exists.
- Rapid toggle open/close: panel ends in a stable visible/hidden state.
- Tooltip near screen edge: stays readable (clamp on-screen).
- Non-DM authority client: panel not shown.

## Key Entities

- **Skill Tree UI**: DM HUD panel (`gui/dm/skill_tree.tscn`).
- **SkillTreeDoodad**: World interact entry (`doodads/skill_tree.tscn`).
- **DM tree / Dad tree**: Two tabbed node sets (9 + ult each).

## Assumptions

- “TSB” remains the ultimate display name until a later story expands the acronym in UI.
- Passive effect strings are flavor for tooltips until a gameplay story binds numbers.

## Out of Scope

- Applying passives to knightlings, gremlins, goblins, or the DM.
- Mana / XP / iron / Fantasy Level **spend** to unlock.
- Unlock prerequisite graphs that grant real power.
- Spawning **TSB**, knightlings, gremlins, traps, or invisibility.
- PP skill trees.
- Redesigning Skill Tree **world** doodad art (US-032 placement stays).
