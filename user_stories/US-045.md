# US-045: Skill Tree passive — Bemidji Cold

**Status**: Draft  
**Source**: James — gameplay for Dad tree passive from US-035  
**Priority**: P2  
**Roles**: Dungeon Master

## User Story

As the Dungeon Master, when I **own** the Skill Tree passive **Bemidji Cold**, blizzard duration increases so the node’s tooltip matches live play.


## Context

US-031 Bemidji Blizzard; US-035 Dad UI. UI copy lives on the Dad tab (US-035). This story owns the **gameplay effect** only.

## Open defaults (confirm with James)

| Topic | Default for v1 | Why |
|---|---|---|
| Scope | **Gameplay** — implement the passive effect when the matching Skill Tree node is **owned** on the host. | Director: not UI-only. |
| Unlock / spend | Ownership is earned via **[US-054](US-054.md)** skill-point spend + gates. This story only applies the **effect while owned**. Harness/debug may force-own for isolated tests. | Spend economy centralized in US-054. |
| UI | Labels/tooltips/icons stay US-034 (DM) / US-035 (Dad). This story does not redo panel art. | Already signed. |
| Ultimates | **Out of scope** (TSB; Dad All Powerful / US-021). | Passives only. |
| Stacking | One rank; owning is boolean. | Simple v1. |
| Authority | Host evaluates ownership and applies combat/world effects; replicate outcomes peers need. | Matches mana/unlock patterns. |

## Independent Test

Force-own **Bemidji Cold** on the host (debug or harness). Verify: Increase duration of blizzard. Observe a control case with the node **not** owned where the bonus does not apply. Peers see the same combat/world outcome. Unequip/clear ownership (if supported) or start a fresh match without ownership and confirm baseline returns.

## Acceptance Criteria

1. **Given** **Bemidji Cold** is **not** owned, **When** the related system runs, **Then** baseline behavior from the referenced stories applies (no this-passive bonus).
2. **Given** **Bemidji Cold** is **owned** on the host, **When** the related system runs, **Then** Increase duration of blizzard.
3. **Given** ownership flips mid-match (if supported), **When** the next relevant action runs, **Then** the effect matches current ownership without requiring a full reconnect.
4. **Given** multiple peers, **When** the effect changes the world or combat, **Then** all peers observe the same authoritative outcome.
5. **Given** only UI interaction without ownership, **When** the player views the US-035 node, **Then** labels/tooltips still match US-035 and no effect applies until owned.

## Functional Requirements

- **FR-001**: Host MUST track ownership of skill id `bemidji_cold` (or equivalent) for this passive.
- **FR-002**: While owned, the host MUST apply: Increase duration of blizzard. Suggested: blizzard pocket duration ×1.5 (e.g. 8s→12s) while owned.
- **FR-003**: While not owned, the host MUST NOT apply this passive’s bonus.
- **FR-004**: This story MUST NOT implement Skill Tree currency spend, row unlock gates, or ultimates.
- **FR-005**: UI labels/tooltips remain US-035; do not regress the Dad tab copy.
- **FR-006**: Effect application MUST be host-authoritative; clients MUST NOT grant the bonus unilaterally.

## Multiplayer Requirements

- **MR-001**: Ownership and effect outcomes MUST agree across peers.
- **MR-002**: Late joiners MUST receive current ownership (or re-derive from host snapshot) before relying on the bonus.

## Edge Cases

- Own then DM death/respawn: ownership persists for the match unless a later rule clears trees on death (default: **persists**).
- Related unlock missing (e.g. knightling locked): owning this passive does not by itself unlock the base ability; it only modifies behavior when that system runs.
- Stacking with other passives: combine unless a conflict is documented in a later balance pass.

## Key Entities

- **Skill ownership**: Host flag for `bemidji_cold`.
- **Bemidji Cold**: Passive effect described above.

## Assumptions

- Tooltip numbers may be flavor until tunables are locked in playtest.
- Base systems named in Context exist enough to hook (stubs OK with harness force).

## Out of Scope

- Ultimates (TSB; Dad All Powerful / US-021).
- Redesigning US-035 panel chrome.
- Full skill-tree spend economy.
- Other passives (each has its own US).

## Required New Art Assets

None required for this passive beyond existing UI icons from US-035.
