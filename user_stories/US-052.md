# US-052: Skill Tree passive — Dad Reflexes

**Status**: Draft  
**Source**: James — gameplay for Dad tree passive from US-035; effect is 1.5× DM movement speed (not a dash)  
**Priority**: P2  
**Roles**: Dungeon Master

## User Story

As the Dungeon Master, when I **own** the Skill Tree passive **Dad Reflexes**, my movement speed is **1.5×** baseline so the node’s tooltip matches live play.


## Context

DM locomotion (`dm.gd` / walk state). US-035 UI. UI copy lives on the Dad tab (US-035); this node’s effect text MUST read as increased DM movement speed, not a dash. This story owns the **gameplay effect** only. There is **no** dash input, cooldown, displacement burst, or i-frames.

## Open defaults (confirm with James)

| Topic | Default for v1 | Why |
|---|---|---|
| Scope | **Gameplay** — implement the passive effect when the matching Skill Tree node is **owned** on the host. | Director: not UI-only. |
| Unlock / spend | Ownership is earned via **[US-054](US-054.md)** skill-point spend + gates. This story only applies the **effect while owned**. Harness/debug may force-own for isolated tests. | Spend economy centralized in US-054. |
| UI | Labels/icons stay US-034 (DM) / US-035 (Dad). This node’s **effect tooltip** MUST describe 1.5× DM movement speed (not dash). This story does not redo panel art. | Copy must match the live effect. |

| Authority | Host evaluates ownership and applies the speed; replicate locomotion peers already see. | Matches mana/unlock patterns. |

## Independent Test

Force-own **Dad Reflexes** on the host (debug or harness). Verify: DM movement speed is **1.5×** the not-owned baseline (same input, same ground). Observe a control case with the node **not** owned where speed is baseline. Peers see the same locomotion. Unequip/clear ownership (if supported) or start a fresh match without ownership and confirm baseline speed returns. Confirm no dash action is granted.

## Acceptance Criteria

1. **Given** **Dad Reflexes** is **not** owned, **When** the DM moves, **Then** baseline DM movement speed from existing locomotion applies (no this-passive bonus, no dash).
2. **Given** **Dad Reflexes** is **owned** on the host, **When** the DM moves, **Then** movement speed is **1.5×** the not-owned baseline. The DM MUST NOT gain a dash ability.
3. **Given** ownership flips mid-match (if supported), **When** the next movement tick runs, **Then** speed matches current ownership without requiring a full reconnect.
4. **Given** multiple peers, **When** the owned DM moves at the boosted speed, **Then** all peers observe the same authoritative locomotion.
5. **Given** only UI interaction without ownership, **When** the player views the US-035 node, **Then** the tooltip describes 1.5× DM movement speed and no effect applies until owned.

## Functional Requirements

- **FR-001**: Host MUST track ownership of skill id `dad_reflexes` (or equivalent) for this passive.
- **FR-002**: While owned, the host MUST apply **1.5× DM movement speed** to normal locomotion (walk / analog move). MUST NOT add a dash input, dash cooldown, burst displacement, or i-frames.
- **FR-003**: While not owned, the host MUST NOT apply this passive’s bonus; DM speed MUST be baseline.
- **FR-004**: This story MUST NOT implement Skill Tree currency spend, row unlock gates, or ultimates.
- **FR-005**: Dad tab tooltip for this node MUST describe 1.5× DM movement speed (update US-035 copy for this node if it still says dash). Do not regress other Dad tab copy.
- **FR-006**: Effect application MUST be host-authoritative; clients MUST NOT grant the bonus unilaterally.

## Multiplayer Requirements

- **MR-001**: Ownership and locomotion outcomes MUST agree across peers.
- **MR-002**: Late joiners MUST receive current ownership (or re-derive from host snapshot) before relying on the bonus.

## Edge Cases

- Own then DM death/respawn: ownership persists for the match unless a later rule clears trees on death (default: **persists**); boosted speed applies again when the DM is moving.
- Dew slick / knockback / interior clamp: still apply; this passive only scales **intended move speed**, not knockback distance.
- Stacking with other passives: multiply 1.5× onto baseline unless a conflict is documented in a later balance pass.

## Key Entities

- **Skill ownership**: Host flag for `dad_reflexes`.
- **Dad Reflexes**: 1.5× DM movement speed while owned.

## Assumptions

- Baseline DM move speed is whatever locomotion already uses when the node is not owned; 1.5× is relative to that, not a hardcoded 450 unless baseline is 300.
- No new art is required for a speed multiplier.

## Out of Scope

- Dash ability, dash VFX, dash input, i-frames.
- Ultimates (TSB; Dad All Powerful / US-021).
- Redesigning US-035 panel chrome.
- Full skill-tree spend economy.
- Other passives (each has its own US).

## Required New Art Assets

None.
