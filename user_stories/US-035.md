# US-035: Dad Skill Tree content (UI only)

**Status**: Draft  
**Source**: James — fill Dad tab placeholders from US-034; Frost / Fire / Control + Dad All Powerful  
**Priority**: P2  
**Roles**: Dungeon Master

## User Story

As the Dungeon Master, I open the **Dad** tab of the Skill Tree and see real **Frost / Fire / Control** passives plus ultimate **Dad All Powerful**, with hover tooltips — still without this story spending currency, applying passives, or running endgame form logic.

## Context

US-034 shipped (or is shipping) the Skill Tree **shell**: DM + Dad tabs, 3×3 + ultimate layout, tooltips, locked/unlocked chrome, entry via Skill Tree doodad → `DmManager._show_skill_tree_hud` → `DmHud._toggle_skill_tree_hud` (`gui/dm/skill_tree.tscn`). The **Dad** tab is explicitly **placeholders** (US-034 FR-005).

This story **replaces Dad placeholders** with James’s locked copy. It does **not** re-open DM tree content (Lightning / Gremlins / Goblins / TSB). Panel chrome, tabs, node frames, and tooltip chrome from US-034 are **reused**; only **new Dad content art** is required here.

**Dad All Powerful** as a live endgame ability remains **US-021** (unlock via US-019 cube, once-per-match form, etc.). This story’s ultimate node is **UI label + tooltip only** until a later spend/apply story binds it.

## Dad tree content (copy locked for UI labels/tooltips)

**Row 1 — Frost**  
1. **Bemidji Cold** — Increase duration of blizzard.  
2. **T-Shirt in December** — Add a frost trail behind you.  
3. **Put a Sweater On** — Blizzard now does damage.  

**Row 2 — Fire**  
1. **Stoke** — Increase fireball radius.  
2. **Full Cord** — Reduce cooldown and mana cost of fireball.  
3. **Everything Burns** — Fireball now destroys resources.  

**Row 3 — Control**  
1. **Thermostat Lock** — Paper Pushers lose one inventory slot.  
2. **Dad Reflexes** — Gain dash ability.  
3. **Grounded** — Paper Pushers can only survive in Fantasy for 3 seconds.  

**Ultimate:** **Dad All Powerful** — Become Dad, All Powerful.

(These strings are **UI copy only** in this story.)

## Independent Test

As DM, open Skill Tree (existing path), select **Dad** tab. See 3×3 passives labeled with the nine names above in Frost / Fire / Control row order, plus ultimate **Dad All Powerful**. Hover each: tooltip shows name + short effect text. Row marks read Frost / Fire / Control (or icons). Locked/unlocked chrome still visual-only. Clicking nodes does not change mana, blizzard/fireball stats, inventory slots, dash, Fantasy timers, or activate US-021. DM tab content from US-034 remains intact. Close works as before.

## Acceptance Criteria

1. **Given** the Skill Tree UI from US-034, **When** the DM opens the **Dad** tab, **Then** placeholder Dad names are gone and the nine passives + ultimate use the **Dad tree content** labels above.
2. **Given** the Dad tab layout, **When** nodes are listed, **Then** they follow **3×3 + ultimate** with rows **Frost** (Bemidji Cold, T-Shirt in December, Put a Sweater On), **Fire** (Stoke, Full Cord, Everything Burns), **Control** (Thermostat Lock, Dad Reflexes, Grounded), ultimate **Dad All Powerful**.
3. **Given** any Dad passive or the ultimate, **When** the DM hovers/focuses it, **Then** the tooltip shows that node’s **name** and **short effect text** from the Dad tree content list.
4. **Given** row/category chrome, **When** the Dad tab is shown, **Then** Frost, Fire, and Control are identifiable (label and/or icon).
5. **Given** locked/unlocked chrome, **When** Dad nodes render, **Then** states remain visual-only with **no** spend/apply from this story (AC aligned with US-034).
6. **Given** the DM clicks a Dad node in this story’s build, **When** the click resolves, **Then** no blizzard/fireball/inventory/dash/Fantasy-timer/US-021 form side effect is triggered by this UI.
7. **Given** the **DM** tab, **When** opened after this story, **Then** US-034 DM tree labels (Lightning / Gremlins / Goblins / TSB) are unchanged by this story.
8. **Given** open/close via the existing entry path, **When** toggled, **Then** behavior stays as US-034 (this story does not change entry).

## Functional Requirements

- **FR-001**: Dad tab node labels and tooltip bodies MUST match the **Dad tree content** section (UI copy). This **supersedes** US-034 FR-005 placeholders for the Dad tree.
- **FR-002**: Dad layout MUST remain **9 passives + 1 ultimate** in **3×3 + ult**, rows Frost / Fire / Control.
- **FR-003**: Row/category identification for Frost, Fire, and Control MUST be visible on the Dad tab.
- **FR-004**: Hover/focus tooltips MUST continue to show **name + short effect text** for every Dad node (reuse US-034 tooltip chrome).
- **FR-005**: This story MUST remain **UI-only**: no currency spend, no host unlock writes that grant power, no passive application, no dash grant, no PP inventory mutation, no blizzard/fireball combat changes, no US-021 activation.
- **FR-006**: Entry/open/close path MUST stay US-034’s doodad → `DmManager` → `DmHud` toggle. Wire content into existing `gui/dm/skill_tree` Dad tab.
- **FR-007**: DM tab content from US-034 MUST NOT be regressively cleared or renamed by this story.
- **FR-008**: Missing new Dad icons MUST NOT block labeled buttons + tooltips (placeholders until Art lands).

## Multiplayer Requirements

- **MR-001**: Panel open state remains local DM UI (US-034). No new host skill-unlock replication required for this UI-only story.

## Edge Cases

- US-034 shell not merged yet: this story depends on Dad tab existing; implement against US-034 panel.
- US-021 already unlocked in match: Skill Tree ultimate is still display-only here; activation stays US-021’s own HUD/ability path.
- Tooltip text longer than placeholders: clamp on-screen like US-034.

- **Dad tree**: Frost / Fire / Control passives + Dad All Powerful ult on the Dad tab.

- Spend/unlock economy for the skill tree.
- Activating or transforming via **Dad All Powerful** (US-021 / US-019).
- Changing DM tree (US-034) content.
- Redesigning panel/tab/frame/tooltip chrome already listed under US-034 Art (unless a bug forces a fix).
- PP-facing skill UI.
