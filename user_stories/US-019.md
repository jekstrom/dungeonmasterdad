# US-019: some kind of tube combines the three Dew cans

**Status**: Draft  
**Source**: `ideas.md` — Dungeon  
**Priority**: P3  
**Roles**: Dungeon Master

## User Story

As the Dungeon Master, I find a tube in the dungeon that works like Diablo II's Horadric Cube so that I can combine the green Mountain Dew, Baja Blast, and Code Red cans to unlock Dad All Powerful.

## Context

No crafting container exists. The three cans come from US-016 (green Dew), US-017 (Baja Blast), and US-018 (Code Red). Dad All Powerful's effect is US-021. Ideas.md: "some sort of tube" / "combine all 3 cans of mt dew to unlock 'dad all powerful' ability."

## Independent Test

Pick up the tube. Open it, place the three distinct Dew cans in its slots, transmute. The cans are consumed and Dad All Powerful unlocks. Transmute with the wrong set fails and does not consume items. The tube cannot be used by Paper Pushers.

## Acceptance Criteria

1. **Given** a generated dungeon, **When** generation completes, **Then** a 'some kind of tube' pickup or interactable exists in a reachable cell that is not entrance or exit.
2. **Given** the DM has the tube, **When** they open it, **Then** they see a small crafting grid (suggested 2×2 or 3 slots) that can hold DM items.
3. **Given** the three distinct cans (green Dew, Baja Blast, Code Red) are in the tube and nothing else is required, **When** the DM transmutes, **Then** the three cans are consumed and Dad All Powerful is unlocked (US-021).
4. **Given** fewer than three cans, or three copies of the same flavor, **When** they transmute, **Then** the recipe fails, items stay in the tube, and no unlock occurs.
5. **Given** extra unrelated items in the tube with the three cans, **When** they transmute, **Then** the recipe fails (strict recipe) unless the extra slots are empty.
6. **Given** Dad All Powerful is already unlocked, **When** they transmute the recipe again, **Then** it fails or no-ops; cans are not consumed a second time.
7. **Given** a Paper Pusher, **When** they try to pick up or open the tube, **Then** they cannot use it.

## Functional Requirements

- **FR-001**: The tube MUST be a DM-only container with a small slot count (3 or 4).
- **FR-002**: The server MUST implement a transmute action that matches recipes against slot contents.
- **FR-003**: The only required recipe in this story is: Green Dew + Baja Blast + Code Red → unlock Dad All Powerful.
- **FR-004**: Successful transmute MUST consume exactly the recipe inputs.
- **FR-005**: Failed transmute MUST NOT consume inputs and MUST NOT unlock anything.
- **FR-006**: Tube contents MUST persist in the DM's inventory/container state if the UI is closed.
- **FR-007**: Transmute and unlock MUST be host-authoritative.
- **FR-008**: Cans used as mana (green Dew auto-use) MUST still be representable as held items if they are needed for the recipe — green Dew that was auto-consumed for mana cannot be tubed. If green Dew auto-uses, the dungeon MUST also provide a cubable can instance, or auto-use must not apply to the first can reserved for crafting. Default: green Dew pickups after knightling unlock may be kept as items (toggle auto-use off for cubable cans; mana grant can be a use-action instead of auto).

## Multiplayer Requirements

- **MR-001**: Only the DM's client shows the tube UI; the server still owns contents.
- **MR-002**: Unlock replication follows US-021.

## Edge Cases

- Tube dropped on death: it drops as a DM-only pickup at the corpse; Paper Pushers cannot loot it.
- Transmute during disconnect: server completes or rejects atomically; no half-consumed can set.
- Two green Dews + Baja: fail.

## Key Entities

- **some kind of Tube**: Horadric-cube analog.
- **Dew Cans**: Green, Baja Blast, Code Red.
- **Transmute**: Server recipe match.

## Assumptions

- Future recipes may be added; this story does not require them.
- The tube is found, not built.

## Out of Scope

- Dad All Powerful combat effect (US-021).
- Can cozy (US-020).
