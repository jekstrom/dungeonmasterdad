# US-054: Skill Tree — spending skill points

**Status**: Draft  
**Source**: James — column costs, Fantasy/Reality row gates, ultimate prereqs  
**Priority**: P1  
**Roles**: Dungeon Master

## User Story

As the Dungeon Master, I spend **skill points** on Skill Tree nodes (DM and Dad tabs) so unlocks follow clear column costs and Fantasy / Reality progression gates — instead of free ownership.

## Context

US-034 / US-035 own Skill Tree **UI** (tabs, labels, tooltips, owned chrome). US-036–US-053 own each **passive’s gameplay effect** when a node is owned. Those passives’ Open default was “owned with no currency.” **This story supersedes that** for how ownership is earned: spend + gates.

Ultimates (**TSB**, **Dad All Powerful**) are purchase-gated here; their *effects* stay out of scope (TSB TBD; Dad All Powerful **US-021**).

Fantasy Level (`DmManager.fantasy_level`) and Reality Level (`PlayerManager` / US-008 factories) already exist as progression integers.

## Locked rules (James)

| Rule | Value |
|---|---|
| Column 1 passive cost | **1** skill point |
| Column 2 passive cost | **2** skill points |
| Column 3 passive cost | **3** skill points |
| Row 2 purchasable when | **Fantasy Level ≥ 30%** (see Open defaults for % → number) |
| Row 3 purchasable when | **Reality Level ≥ 80%** (see Open defaults) |
| Ultimate purchasable when | **≥1 owned unlock in each of rows 1, 2, and 3** on **that tree** |

Columns = left→right within a row (col1 / col2 / col3). Rows = themes (DM: Lightning / Gremlins / Goblins; Dad: Frost / Fire / Control).

## Independent Test

Start with SP = 0, FL = 0, RL = 0. Row 1 col1 is available but purchase fails without SP. Grant SP (or raise FL to earn SP). Buy a Row 1 col1 node for 1 SP; node becomes owned; SP decreases. Attempt Row 2 before FL ≥ 30: rejected with feedback. Raise FL to ≥ 30; buy Row 2 with enough SP. Attempt Row 3 before RL ≥ 80: rejected. Raise RL; buy Row 3. With ≥1 owned in each row on that tree and ≥5 SP, buy the ultimate; without a row covered, ultimate rejects. Repeat gates on the other tree. Peers see the same owned set and SP. Passive gameplay still only runs when owned (US-036–053).

## Acceptance Criteria

1. **Given** a column-1 passive on either tree that is unlocked by gates, **When** the DM spends with ≥1 SP, **Then** the host deducts **1** SP and marks the node owned.
2. **Given** a column-2 / column-3 passive (gates OK), **When** spent successfully, **Then** cost is **2** / **3** SP respectively and the node is owned.
3. **Given** Fantasy Level below the Row 2 threshold, **When** the DM tries to buy any Row 2 node, **Then** the spend is rejected, SP unchanged, node not owned, and UI shows clear gate feedback.
4. **Given** Fantasy Level at/above the Row 2 threshold and enough SP, **When** they buy a Row 2 node, **Then** the spend succeeds (subject to cost).
5. **Given** Reality Level below the Row 3 threshold, **When** they try to buy any Row 3 node, **Then** reject with feedback; SP unchanged.
6. **Given** Reality Level at/above the Row 3 threshold and enough SP, **When** they buy a Row 3 node, **Then** the spend succeeds (subject to cost).
7. **Given** Row 1, **When** FL/RL are 0, **Then** Row 1 nodes are not FL/RL-gated (only SP / already-owned rules apply).
8. **Given** a tree with fewer than one owned passive in any of rows 1–3, **When** the DM tries to buy that tree’s ultimate, **Then** reject with prereq feedback.
9. **Given** ≥1 owned in each of rows 1–3 on that tree and enough SP for the ultimate cost, **When** they buy the ultimate, **Then** SP deducts, ultimate is owned (effect body still US-021 / future TSB story).
10. **Given** a node already owned, **When** they try to buy it again, **Then** reject; SP unchanged.
11. **Given** insufficient SP, **When** any purchase is attempted, **Then** reject with feedback; ownership unchanged.
12. **Given** another peer, **When** a spend succeeds or fails, **Then** all peers agree on SP remaining and owned nodes (host authority).

## Functional Requirements

- **FR-001**: Host MUST maintain a DM **skill point** integer balance and replicate it to the DM client for UI.
- **FR-002**: Passive purchase costs MUST be **1 / 2 / 3** SP for columns **1 / 2 / 3** on both trees.
- **FR-003**: Row 2 nodes MUST be purchasable only when Fantasy Level meets the signed threshold (Open default: **≥ 30**).
- **FR-004**: Row 3 nodes MUST be purchasable only when Reality Level meets the signed threshold (Open default: **≥ 80**).
- **FR-005**: Row 1 nodes MUST NOT require FL/RL gates.
- **FR-006**: A tree’s ultimate MUST require **≥1 owned passive in each of rows 1, 2, and 3** on **that** tree before purchase.
- **FR-007**: Ultimate SP cost MUST use the signed Open default (**5** unless James overrides).
- **FR-008**: Successful spend MUST be atomic on the host: deduct SP and set owned together, or neither.
- **FR-009**: Failed spends MUST NOT change SP or ownership and MUST surface distinct UI feedback (SP / row gate / ultimate prereq / already owned).
- **FR-010**: Wire purchase attempts through existing Skill Tree UI (US-034/035); do not invent a second tree screen.
- **FR-011**: US-036–053 passive **effects** MUST key off ownership produced by this story (harness may still force-own for isolated effect tests).
- **FR-012**: SP income MUST follow the signed Open default (v1: **+1 SP per +1 Fantasy Level**).

## Multiplayer Requirements

- **MR-001**: Only the host accepts spends; clients request and display results.
- **MR-002**: Late join MUST receive current SP, owned nodes (both trees), and enough FL/RL to render gates correctly.

## Edge Cases

- FL drops (if ever possible): already-owned nodes stay owned; new Row 2 buys use current FL.
- Buying ultimate then refunds (unsupported): ultimate stays owned.
- Concurrent double-click buy: one success max (host serializes).
- Dad vs DM trees: SP shared; row prereqs are per-tree for ultimates.
- Systems note: Director may already have partial spend plumbing — Gameplay should hook UI to host spend API without duplicating economy.

## Key Entities

- **Skill points (SP)**: Spend currency for tree nodes.
- **Owned node**: Host flag consumed by US-036–053 / ultimate effect stories.
- **Row / column gates**: FL, RL, and per-tree ultimate prereqs.

## Assumptions

- Percent gates map to absolute levels vs cap 100 until James defines otherwise.
- Paper Pushers never spend on this tree.

## Out of Scope

- Implementing passive **effects** (US-036–053).
- TSB summon body; Dad All Powerful combat form (**US-021**).
- Redesigning US-034/035 art beyond spend/gate feedback.
- PP skill trees; refunds; per-tree separate SP pools (unless James overrides).
