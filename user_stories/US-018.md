# US-018: Code Red dragon unlocks fireball

**Status**: Draft  
**Source**: `ideas.md` — Dungeon  
**Priority**: P2  
**Roles**: Dungeon Master

## User Story

As the Dungeon Master, I defeat the Code Red dragon in the dungeon to unlock fireball so that I have a ranged spell for the overworld fight.

## Context

Fireball already exists as a spell scene, HUD button, projectile spawner, and `DmUnlocks["fireball"]`. Code Red exists as a pickup whose effect unlocks fireball and adds Fantasy Level. There is no dragon boss; the pickup can appear without a fight.

This story makes **the dragon the gate**: fireball unlocks when the Code Red dragon dies, not from a loose floor can alone. The can still exists as loot for the cube (US-019).

## Independent Test

Find the Code Red dragon, defeat it, receive Code Red, fireball unlocks on the HUD. Before the kill, the fireball button does not cast. After the kill, fireball casts when mana is sufficient (US-014).

## Acceptance Criteria

1. **Given** a generated dungeon, **When** generation completes, **Then** it contains one Code Red dragon boss in a reachable room that is not the entrance cell.
2. **Given** the dragon reaches 0 HP, **When** death resolves, **Then** a Code Red can is granted or dropped and fireball is unlocked for the DM.
3. **Given** fireball is locked, **When** the DM presses the fireball control, **Then** no projectile is spawned and no mana is spent.
4. **Given** fireball is unlocked and mana ≥ cost, **When** the DM completes a fireball cast, **Then** mana is spent and the existing fireball projectile flow runs.
5. **Given** a Code Red can is on the floor after the fight, **When** the DM picks it up, **Then** they hold it as a cube ingredient even if fireball is already unlocked.
6. **Given** a Paper Pusher, **When** they hit the dragon, **Then** they deal no meaningful progress by default (they cannot be in the dungeon — US-015); the DM is the intended killer.

## Functional Requirements

- **FR-001**: The dungeon MUST place exactly one Code Red dragon per match unless tests skip bosses.
- **FR-002**: Dragon death MUST unlock fireball via `DmUnlocks.unlock("fireball")` (or equivalent) on the server.
- **FR-003**: Fireball MUST cost mana (US-014, suggested 15). The current HUD behavior that *adds* Fantasy Level on button press MUST NOT remain the spend model.
- **FR-004**: Fireball projectile damage, targeting, and replication MUST reuse the existing spell pipeline.
- **FR-005**: Code Red loot MUST be a distinct can item usable in US-019 even after unlock.
- **FR-006**: A loose Code Red pickup that is not dragon loot MUST NOT be required; if one exists for testing, picking it up may still unlock fireball to preserve current `ItemEffectUnlockFireball` during transition.

## Multiplayer Requirements

- **MR-001**: Unlock and projectile spawns MUST be host-authoritative.
- **MR-002**: All peers MUST see the same fireball shots.

## Edge Cases

- Dragon and Baja Blast boss in the same dungeon: both must be reachable, not stacked on one cell.
- Fireball unlocked then `DmUnlocks.lock("fireball")` from some other system: treat as locked again; dragon kill is not automatically reapplied.
- Casting fireball at 0 mana: rejected (US-014).

## Key Entities

- **Code Red Dragon**: Dungeon boss.
- **Code Red Can**: Unlock loot and cube ingredient.
- **Fireball**: Existing DM spell, now mana-paid and dragon-gated.

## Assumptions

- Existing fireball VFX/damage stay unless combat tuning says otherwise.
- Fantasy Level grant currently on the Code Red effect (+50) may remain as a bonus on dragon death.

## Out of Scope

- Bemidji Blizzard (US-017).
- Cube recipe (US-019).
- Dad All Powerful (US-021).
