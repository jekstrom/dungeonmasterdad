# US-055: DM minion spawns near the DM (random radius)

**Status**: Draft  
**Source**: James — goblins, gremlins, and knights spawn in a random radius near the DM  
**Priority**: P2  
**Roles**: Dungeon Master

## User Story

As the Dungeon Master, when I summon **goblins**, **gremlins**, or **knightlings**, they appear at a **random walkable point near me** so minions reinforce where I am standing — not at a fixed map corner, world origin, or other off-DM spot.

## Context

DM HUD already summons **gremlins** and **knightlings** (`DmManager` → `MultiplayerSpawner.spawn_gremlin` / `spawn_knight`). Today those paths do **not** place units relative to the live DM:

- Gremlin: instantiated with **no** near-DM position set (defaults / origin behavior).
- Knightling: position is a small random offset near **world (0,0)** (`randi() % 50`), not the DM.
- Goblin: raid behavior is US-011; a dedicated DM HUD goblin summon may be missing or incomplete — this story still **requires** the same near-DM placement whenever the DM can summon a goblin.

Post-spawn AI stays in other stories (US-011 raids, US-012 lethal strikes, US-013 relocate / flee / inland bias). **US-041 Crib Death** auto-summons at the **dungeon exit** and is **out of scope** here. Procedural dungeon catalog spawns are out of scope.

Grid: `DungeonGrid.CELL_PX` = **128**.

## Open defaults (confirm with James)

| Topic | Default for v1 | Why |
|---|---|---|
| Units covered | **Goblin**, **gremlin**, **knightling** — same placement rules for all DM summons of these three. | James ask. |
| Anchor | Live **DM body** world position / cell at cast resolve time (host). | “Near the DM.” |
| Radius | Uniform among walkable candidate **cells** with Chebyshev distance from DM cell in **[1, 3]** inclusive (min 1 so not on the DM’s cell; max 3 ≈ 384px). | Clear cell math; feels close without stacking on the DM. |
| Sampling | Host picks one uniform random eligible cell, then places at cell center (or existing monster foot offset). If Chain Lightning (US-038) spawns 3 knightlings, **each** rolls independently in the same radius. | Simple; avoids identical stacking. |
| Walkable-only | Candidates MUST be walkable / nav-valid: no cliffs, off-map, void, or permanently blocked solids. Prefer same walkability notion as US-013 pathing. | Matches “don’t stuck spawn.” |
| Inland bias at spawn | **Soft preference**: among eligible cells, prefer inland (farther from cliffs / map edge) — same spirit as US-013 FR-012, applied at spawn pick. | Stops edge-hugging spawns. |
| No cell available | Do **not** spawn; do **not** spend mana / Fantasy cost; surface fail feedback. Optional fallback: nearest walkable cell within Chebyshev ≤ 5 — **off by default** until James wants it. | Fail closed. |
| Host authority | Host chooses position and instantiates; peers see the unit at that position. | Matches other summons. |
| Goblin HUD | If goblin DM summon UI/ability is missing, restore/add a minimal summon path that uses this placement (cost/unlock can stay US-014 / later; do not invent raid AI here). | Cover all three types. |
| US-013 interaction | Placement only. After spawn, gremlin AI (pickup, 2× speed, flee PPs, inland pathing) remains US-013. | Separation of concerns. |
| US-041 | Crib Death exit spawns **unchanged** (not near-DM). | Explicit exception. |

## Independent Test

Stand as DM on walkable ground away from world origin. Summon a gremlin: it appears on a walkable cell within Chebyshev 1–3 of the DM, not at (0,0). Summon a knightling: same. Summon a goblin (once HUD/ability exists): same. Repeat several times: positions vary. Stand next to a cliff: spawns stay walkable and bias inland. With Chain Lightning owned, three knightlings each land in the radius (may differ). Attempt spawn with no eligible cell (contrived blocked ring): no unit, no cost spent.

## Acceptance Criteria

1. **Given** the DM successfully summons a **gremlin**, **When** the host places it, **Then** its spawn position is a walkable cell with Chebyshev distance from the DM’s cell in **[1, 3]** (Open defaults unless overridden).
2. **Given** the DM successfully summons a **knightling**, **When** the host places it, **Then** the same near-DM radius / walkable rules apply (not world-origin jitter).
3. **Given** the DM successfully summons a **goblin**, **When** the host places it, **Then** the same near-DM radius / walkable rules apply.
4. **Given** multiple summons of the same type, **When** positions are compared across casts, **Then** they are not a single fixed off-DM point (random among eligible cells).
5. **Given** a candidate cell that is cliff / off-map / non-walkable, **When** the host samples, **Then** that cell is never chosen.
6. **Given** inland and cliff-edge walkable candidates both exist in range, **When** the host picks, **Then** inland candidates are preferred (soft bias).
7. **Given** no eligible cell in range, **When** the DM tries to summon, **Then** no unit spawns and the summon cost is not consumed.
8. **Given** Chain Lightning causes multiple knightlings on one cast, **When** they spawn, **Then** each independently uses the near-DM radius rules.
9. **Given** another peer, **When** a minion spawns, **Then** all peers see it at the host-chosen near-DM position.
10. **Given** a US-041 Crib Death auto-gremlin, **When** it spawns, **Then** it still uses the **exit** placement (this story does not relocate it to the DM).

## Functional Requirements

- **FR-001**: Host MUST implement a shared DM-minion spawn placement helper used by goblin, gremlin, and knightling **DM summons**.
- **FR-002**: Placement MUST sample a walkable cell within the signed radius of the live DM (Open default: Chebyshev **[1, 3]**).
- **FR-003**: Placement MUST NOT use a fixed map corner, authored marker, or world-origin random offset as the primary rule.
- **FR-004**: Placement MUST be host-authoritative; clients MUST NOT pick a divergent position.
- **FR-005**: If no eligible cell exists, the summon MUST fail without spawning and without consuming the summon cost.
- **FR-006**: Soft inland / away-from-cliff preference MUST apply when choosing among eligible cells (aligned with US-013 inland bias spirit).
- **FR-007**: Multi-unit knightling casts (US-038 Chain Lightning) MUST place **each** unit via the same helper (independent rolls).
- **FR-008**: Goblin DM summon MUST use this helper whenever that summon exists; if missing, Gameplay MUST wire a minimal goblin DM summon path that uses it (raid AI remains US-011).
- **FR-009**: US-041 exit auto-spawns and procedural dungeon monster spawns MUST NOT be forced through this near-DM helper.

## Multiplayer Requirements

- **MR-001**: Only the host selects the spawn cell and instantiates the minion.
- **MR-002**: Late joiners MUST see already-spawned minions at their replicated positions (existing monster replication).

## Edge Cases

- DM moving while cast resolves: use DM position at **host resolve** time.
- DM dead / awaiting respawn: reject summon or use corpse/spectator rules already in place; do not spawn at (0,0).
- DM inside dungeon vs overworld: still near-DM walkable cells in that space.
- Occupied cell (another unit): still allowed unless collision makes it non-walkable; units may overlap slightly — Open default allow.

## Key Entities

- **DM minion summon**: Goblin, gremlin, or knightling spawned from DM HUD / ability cast.
- **Near-DM spawn cell**: Host-chosen walkable cell in the signed Chebyshev band around the DM.

## Assumptions

- Mana / unlock gates stay US-014 / US-016 / Skill Tree as today.
- “Knights” in James’s ask means **knightlings** (US-012), not a new unit.

## Out of Scope

- Goblin raid AI (US-011), knightling lethal rolls (US-012), gremlin relocate/flee/speed (US-013).
- Crib Death exit spawns (US-041).
- Procedural dungeon ambient spawns.
- Changing summon costs or unlocks.

## Required New Art Assets

None. Reuse existing HUD spawn buttons / monster scenes.
